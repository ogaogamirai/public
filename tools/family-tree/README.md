# FamilyTree Studio（家系図スタジオ）

Mermaid を遥かに超える格調高く美しいデザイン、直感的な二刀流編集（GUI ＆ JSON）、そして A4/A3 への美麗な印刷・PDF 出力に対応したスタンドアロン型 Web 家系図作成ツールです。

「**今の小笠原家の家系を４代遡る形（初代が複数組あり、諸家から現世代へ合流する系譜）**」の完全な可視化・編集・印刷に対応しています。

---

## 主な機能と特徴

### 1. 2つの表示形式（祖先遡及型 ＆ 子孫展開型）
- 🏯 **4代祖先系譜モード（複数初代合流）**:
  - 現当主（四代）から4代前（初代・曾祖父母世代）まで遡り、**複数組の初代（父方祖父方、父方祖母方、母方祖父方、母方祖母方など計4組・8名）**が最上段に並び、二代（祖父母）、三代（父母）を経て四代（現当主・兄弟）および次世代（子）へと美しく収束・合流する**対称系譜レイアウト（八重系図・アネンターフェル方式）**。
- 🌿 **子孫展開モード（標準ツリー）**:
  - 初代から子孫へ世代順に分岐・展開する伝統的なツリー表示。
- 画面上部のセレクトボックスからワンクリックで切り替え可能。

### 2. 格調高いデザイン（Mermaid 超えの美麗さ）
- **和モダン・伝統 (Japanese Traditional)**: 生成り和紙テクスチャ、墨文字、藍色（男性）・桜色（女性）の上品な差し色、婚姻の組紐・結線アイコン（⚭）。
- **西洋クラシック (Western Heritage)**: 羊皮紙調の気品ある背景、金色のアクセント、クラシックセリフ書体。
- **洗練モダン (Modern Clean)**: クリーンでフラットなカード、微細なシャドウ、現代的なサンセリフ体。
- **人物カード**: 氏名（大きな毛筆・明朝風）、ふりがな、続柄（初代、当主など）、生没年（元号・西暦併記）、略歴・特記事項を美しく整理。

### 3. 直感的で後から修正しやすい「二刀流」編集
- **GUI ビジュアル編集**:
  - 人物カードをクリックすると編集モーダルが開き、氏名・生没年・続柄・親・配偶者を簡単に変更可能。
  - カードホバー時のクイックボタン（✏️ 編集、💍 配偶者追加、👶 子孫追加、🗑️ 削除）で直感的に系図を拡張。
- **データ直接編集（JSON サイドバー）**:
  - 「📝 構成データ」ボタンで左ペインに JSON エディタを展開。
  - テキストを直接編集して「図に反映」を押すと、リアルタイムに系図へ反映されます。
- **自動保存 & エクスポート**:
  - 変更内容はブラウザ（LocalStorage）に即座に自動保存。
  - 「💾 保存 / 読込」から JSON ファイルのダウンロード・読込が可能。
  - プリセットとして「**小笠原家 四代祖先系譜図**」と「**山田家 三代系図**」をワンクリックで読み込めます。

### 4. A4 / A3 対応の美麗な印刷・PDF 出力
- **`@media print` 最適化**:
  - 印刷時（または PDF 保存時）にはツールバー、ボタン、サイドバーなどの UI 要素が自動的に非表示となり、系図と表題のみが用紙に美しく描画されます。
  - 背景色やカード境界線がかすれない `print-color-adjust: exact` 制御。
  - 「🖨️ 印刷 / PDF」ボタンからワンクリックで印刷プレビューが起動。

## 使い方

1. **起動方法**:
   - `G:\マイドライブ\Tools\family-tree\index.html` を Chrome / Edge などのブラウザで直接開くだけ（ダブルクリックで起動可能。サーバー不要）。
   - 初期状態で「**小笠原家 四代祖先系譜図**」が美麗に表示されます。
2. **編集**:
   - 既存のカードをクリックして名前や情報を書き換えるか、「➕ 人物を追加」で新しい人物を登録。
   - 配偶者や子供を追加したいカードにマウスを重ね、リングアイコン（💍）や子アイコン（👶）を押すと自動で結線されます。
3. **印刷・PDF 保存**:
   - 画面右上の「🖨️ 印刷 / PDF」をクリック。
   - 「印刷プレビューを開く」を押すとブラウザの印刷画面が表示されます。
   - 送信先を「PDF に保存」に指定し、用紙を「横（Landscape）」、「詳細設定」で「背景のグラフィック」にチェックを入れて保存してください。
