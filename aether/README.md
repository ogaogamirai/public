# Aether（公開用コピー）

この `aether/` は、ブラウザ完結型ホワイトボード **Aether** の公開用複製です。
GitHub Pages から起動して利用するための一式（実行ファイル＋テーマ）を置いています。

## 起動

GitHub Pages で公開中：`https://ogaogamirai.github.io/public/aether/`

## 正本との関係

- **正本（バックアップ・開発の場）**: `https://github.com/ogaogamirai/aether`
- この `public/aether/` は公開利用のためのコピー。将来 `ogaogamirai/aether` を private 化しても、こちらから GitHub 起動を継続できる。
- 構成は実行に必要なファイルのみ：`index.html` + JS 一式 + `style.css` + `aether_dsl.txt` + `themes/`

## テーマ

`themes/` にはボードDSL・配布HTMLなどを配置する（GitHub Pages から参照可能）。
